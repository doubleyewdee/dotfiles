# dotfiles
My (shareable) dotfiles for various and sundry apps and systems.

## Testing / Demo
Clone this repo, then `./run.sh` to build and run a Docker container with these dotfiles set up for user `wd`.

## Contents
- `Dockerfile`: Dockerfile to build a container with these dotfiles.
- `run.sh`: script to build and run the Docker container.
- `src/`: various dotfiles and config files. Top-level files have the leading `.` stripped.
